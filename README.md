# BillNexa - Pharmacy Management Platform

A full-scale pharmacy management system for end-to-end pharmacy operations.

## Status
- ✅ Backend (Microservices, REST APIs) — Complete
- ✅ GST Billing Engine — Complete
- ✅ Inventory Management — Complete
- ✅ Invoice & Purchase Module — Complete
- 🔄 Frontend (React UI) — In Progress

## Tech Stack
- **Backend:** .NET Core, C#, Microservices Architecture
- **Database:** SQL Server, T-SQL, Stored Procedures
- **API:** RESTful APIs, Web APIs, JWT Authentication
- **DevOps:** Docker, Git, GitHub

## Key Features
- GST-compliant billing and invoice generation
- Real-time inventory tracking
- Doctor & supplier management
- Sales and purchase return workflows
- Role-based access control (RBAC)
- Automated reporting with export support
